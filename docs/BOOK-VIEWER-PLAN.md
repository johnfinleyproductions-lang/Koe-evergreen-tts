# Native Koe book viewer

Deliver this inside the installed Koe Mac app, alongside its existing capture,
reading, boards and notebook surfaces. Evergreen Core remains the narration
backend; the native app displays original PDFs and plays existing chapter MP3s.
Preserve existing notebooks, highlights, settings and accessibility identity.

- [x] Add Books navigation, original PDF view, zoom and page controls.
- [x] Import both already-prepared books and cached existing narration.
- [x] Persist book/chapter/page/audio position and playback speed.
- [x] Derive page-to-text spans from prepared per-page extraction; follow narrated
  word offsets only where the mapping is sufficiently supported, with manual
  navigation always available.
- [x] Connect native refresh to session-authenticated Core metadata/media, keeping
  downloaded chapters usable offline. Use the app's own sign-in session, never
  extract the browser's cookies or ship internal worker credentials.
- [x] Test model validation, saved place, page following, seek and real audio;
  build and inspect the native UI.
- [x] Back up and replace the installed app with the verified signed bundle,
  retain existing user data, and show both books in native Koe.

No new models, OCR runs or narration generation are required. Preserve the exact
source PDF and existing recorded audio. Page following uses the existing word
timings, which are approximate; this does not promise exact word highlighting
inside scanned PDF images.

## Verification and release

Both prepared books imported into Koe's private library: 56 chapters and 388
original PDF pages, with 15 existing audio chapters initially cached. Real
recordings decoded and played in the native viewer. Zoom, manual navigation,
page entry, seeking, page following and saved-position restoration passed.
The Swift smoke harness also rejects unsafe package paths; page mapping tests
cover UTF-16 offsets and uncertain matches. The Core session/workspace API tests
passed and the endpoints were deployed via Core's canonical release command.

The installed `/Applications/Koe.app` was replaced only after strict signature
verification, retaining the existing bundle identifier and signing certificate.
The prior app remains at
`/Applications/.Koe.before-native-books.20261005-001511.app`.

Koe's connection window reaches the normal Evergreen login page. The user must
sign in once in that window to enable future chapter downloads; a successful
account sign-in has not been automated or claimed as verified. Cached chapters
remain available meanwhile. Remaining narration is still generated by Core's
existing queue.

## Kokoro option (2026-10-05)

The native chapter player now offers a Voice picker: Audiobook Narrator or
Kokoro using Koe's existing configured server and voice. Kokoro uses the imported
source text and its own word timestamps, with a source-word seek slider and
separate saved Kokoro position. It works on chapters without recorded audio and
continues to the next chapter. Stable chunk boundaries allow pause/resume inside
cached passages; cache identity includes the endpoint, voice and exact text.
The original MP3s are retained. Unavailable passages stop with a visible error.

Tests verified 56 chapters and 388 source pages, original recording preservation,
legacy saved-place decoding, voice switching, Kokoro word seek/page follow and
resume, and readiness for chapters awaiting original narration. An actual Kokoro
Heart narration test verified cache persistence, resuming from a word offset,
offline replay with zero network requests, separation between voice profiles,
and explicit errors without skipping content. Native window checks verified the
picker and playback of an uncached chapter.
